1. CATALOGUE PRODUITS
================================================

Zone : /shop
Fichier : src/pages/Shop.tsx, src/components/ShopFilterAndSort.tsx

DESCRIPTION
-----------
Liste paginee des produits avec :
  - Filtres par categorie (Vetements, Accessoires, Papeterie, Edition Limitee)
  - Tri : Par defaut / Popularite / Prix croissant / Prix decroissant
  - Affichage du nombre de resultats

VALEUR BUSINESS : tres haute (point d'entree principal vers l'achat)
FREQUENCE USAGE : tres haute

LIMITES
-------
- Pas de filtre par prix (min/max)
- Pas de filtre par disponibilite stock
- Pas de filtre par taille/couleur


================================================
2. FICHE PRODUIT
================================================

Zone : /product/:id
Fichier : src/pages/SingleProduct.tsx

DESCRIPTION
-----------
Page detaillee d'un produit avec :
  - Image du produit
  - Titre, categorie, prix
  - Selecteurs : taille (XS a 2XL), couleur (6 options), quantite
  - Bouton "Add to cart"
  - Estimation de livraison
  - Dropdowns : Description, Product Details, Delivery Details
  - Section "Similar Products" (3 produits)

VALEUR BUSINESS : tres haute (etape de conversion cle)
FREQUENCE USAGE : tres haute

LIMITES
-------
- Descriptions en Lorem ipsum (faux contenu)
- Date de livraison codee en dur ("Friday, July 26")
- Stock non affiche : on peut ajouter au panier un produit en rupture
- "Similar Products" = 3 premiers produits du catalogue, pas vraiment "similaires"

================================================
4. CHECKOUT
================================================

Zone : /checkout
Fichier : src/pages/Checkout.tsx

DESCRIPTION
-----------
Formulaire de commande en une page :
  - Contact information (email)
  - Shipping information (nom, adresse, ville, region, code postal, telephone)
  - Mode cadeau (voir section 5)
  - Payment (carte / PayPal / eTransfer + champs CB)
  - Order summary (recapitulatif articles + sous-total + livraison + taxes + total)
  - Bouton "Confirm Order"

Mode invite supporte : l'achat fonctionne sans compte utilisateur.

VALEUR BUSINESS : tres haute (conversion finale)
FREQUENCE USAGE : haute

LIMITES
-------
- Pays limites a US / Canada / Mexique - inutilisable pour la France !
- Pas de validation cote serveur des donnees de paiement
- Frais de livraison fixes (5 EUR), pas adaptes au pays/poids
- Pas d'integration paiement reelle (mock)


================================================
5. MODE CADEAU                              [NOUVEAU]
================================================

Zone : /checkout (section dediee)
Fichier : src/pages/Checkout.tsx
PR : #1

DESCRIPTION
-----------
Permet d'acheter un produit pour l'offrir :
  - Case a cocher "C'est un cadeau" dans le checkout
  - Champ message personnalise (300 caracteres max)
  - Adresse de livraison destinataire independante :
      * Nom du destinataire
      * Adresse, ville, code postal, pays
  - Indicateur visuel dans le resume de commande
  - Donnees sauvegardees avec la commande sous l'objet "gift"

VALEUR BUSINESS : haute (panier moyen, B2B, cadeaux clients/collegues)
FREQUENCE USAGE : moyenne (cas relationnel)

LIMITES
-------
- Le masquage du prix est purement visuel cote UI - pas encore propage au bon de livraison physique
- Pas de champ email du destinataire (la confirmation va a l'acheteur)
- Pas de templates de message pre-faits
- Pas de surcout d'emballage cadeau
